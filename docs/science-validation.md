# 科学验证计划

## 双摆

正式镜头必须使用标准双摆运动方程和数值积分（优先 RK4），参数包含杆长、质量、重力和初始角度。两组初始条件只改变一个明确的小角度扰动；输出角度、角速度、端点位置和两轨迹距离。验证能量漂移、时间步长收敛和短时轨迹稳定性，并在画面标注参数来源或“概念示意”。

## 洛伦兹系统

使用 `σ=10, ρ=28, β=8/3` 的经典方程，以固定步长 RK4 积分，验证步长变化对轨迹的影响、有限时间内数值稳定性和双翼结构。洛伦兹吸引子只表示状态空间结构，不表示真实蝴蝶或天气形状。

## 叙事边界

确定性混沌不是纯随机；敏感性不意味着所有扰动都造成巨大后果；区分短期状态预测、长期精确预测和统计性质。1963 年论文引用需核对原始书目信息，避免伪造引文或历史图像。

## 输出证据

每个正式科学场景应保存参数、积分器、步长、采样率和验证结果；渲染组件只消费已计算数据，不在视觉层伪造轨迹。
