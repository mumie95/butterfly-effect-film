# 视觉风格与组件规范

## 视觉方向

黑金古典科学美学：暖黑 `#0C0B0A`、深炭灰 `#191613`、香槟金 `#D8B574`、浅金 `#F0D59A`、象牙白 `#E9E0CE`、铜红 `#B85E42`、弱化标注 `#81786B`。背景使用固定种子颗粒、中心暖光、暗角和低对比参考线；数学主体保持高对比与留白。

## 可复用组件

- `Backdrop`: 暖黑纸张质感、暗角、参考网格。
- `ArcScale`: 可参数化中心、半径、角度、刻度和标签。
- `ScientificLabel`: 年份、公式、单位和状态标注，统一字距与基线。
- `TitleLockup`: 中文宋体标题、英文衬线副标题、章节编号。
- `LineChart`: 帧驱动折线、坐标轴、误差区域和刻度。
- `Trajectory`: 基于采样点的逐帧路径生长，区分真实计算与概念示意。
- `ScientificRig`: 三维装置容器，材质、灯光、相机和比例可配置。

## 动画原则

所有时间由 Remotion 当前帧计算；随机纹理使用固定种子。材质和光照服务于结构可读性，避免霓虹、随机粒子和无意义公式堆叠。二维信息图与 Three.js/R3F 局部三维主体通过同一主题变量合成。
